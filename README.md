# zhpro

私有相册备份工具：手机照片自动备份到自己的电脑，不走任何云端服务器。

> 本仓库只发布安装包，不含源代码。

## 功能

- 手机相册自动备份到电脑指定目录，不经过任何服务器
- 局域网直连传输，速度取决于路由器
- 断点续传，中途断网重连后接着传
- 按 设备 / 年份 / 月份 / 来源 自动整理文件
- 支持浅色 / 深色主题

## 使用步骤

1. 电脑端安装并打开 zhpro
2. 点「连接手机」，屏幕上出现二维码
3. 手机端安装 APK，扫码完成绑定
4. 手机端授权相册权限，开始自动备份
